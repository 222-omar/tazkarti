# 🇪🇬 نظام تنبيهات تذاكر مباريات الأهلي ومنتخب مصر (Tazkarti Alert)

نظام متكامل، سريع، ومجاني بالكامل لمراقبة موقع **تذكرتي (tazkarti.com)** لحظة بلحظة، وإرسال إشعار فوري (**Push Notification**) عالي الأولوية ينبثق على شاشة الهاتف وشاشة القفل بمجرد طرح تذاكر لأي مباراة لـ **منتخب مصر** أو **النادي الأهلي**، أو عند تغير حالة التذاكر (`matchStatus`).

> [!IMPORTANT]
> **نظام تنبيه فقط (Alert-Only):** التطبيق لا يقوم بأي شراء تلقائي أو تخطي كابتشا أو تسجيل دخول آلي. الهدف هو إشعارك فوراً في نفس اللحظة التي تتوفر فيها التذاكر لتتمكن من الدخول وحجزها بنفسك بأمان وقانونية 100%.

## ⚡ لماذا Firebase Cloud Functions؟ (أرخص وأسهل دبلوي)

1. **مجاني بالكامل (0$):**
   - يدخل تحت باقة Firebase المجانية (أول 2 مليون استدعاء شهرياً مجاناً).
   - الفلاتر كده كده بيحتاج Firebase لخدمة الإشعارات (FCM) وقاعدة البيانات (Firestore).
   - لا حاجة لحجز سيرفر شهري VPS أو دفع اشتراكات.
2. **كل شيء في مكان واحد:**
   - الداتابيز (Firestore) + الإشعارات (FCM) + السيرفر (Cloud Function) في نفس المشروع.
3. **أمر دبلوي واحد:**
   - بضغطة زر وأمر واحد: `firebase deploy --only functions,firestore`.

## 🚀 دليل التشغيل والربط خطوة بخطوة

### الخطوة 1: إنشاء مشروع في Firebase Console
1. ادخل على [Firebase Console](https://console.firebase.google.com/) واضغط **Add project**.
2. سمّ المشروع (مثلاً: `tazkarti-alert`).
3. من القائمة الجانبية:
   - فعّل **Firestore Database** (اختر وضع Production).
   - فعّل **Cloud Messaging** (FCM).

---

### الخطوة 2: ربط تطبيق Flutter بالمشروع
1. تأكد من تثبيت أدوات الفايربيز:
   ```bash
   npm install -g firebase-tools
   dart pub global activate flutterfire_cli
   ```
2. سجل دخولك إلى فايربيز:
   ```bash
   firebase login
   ```
3. ادخل لمجلد التطبيق وقم بربطه تلقائياً:
   ```bash
   cd d:/tazkarti/app
   flutterfire configure
   ```
   *(اختر مشروعك، وسيتم إنشاء ملفات الربط للأندرويد والآيفون تلقائياً).*

---

### الخطوة 3: نشر السيرفر السحابي (Cloud Functions)
1. ادخل لمجلد `functions`:
   ```bash
   cd d:/tazkarti/functions
   npm install
   ```
2. تأكد من تحديد مشروعك:
   ```bash
   firebase use --add
   ```
3. انشر السيرفر وقواعد البيانات بأمر واحد:
   ```bash
   cd d:/tazkarti
   firebase deploy --only functions,firestore
   ```

بمجرد اكتمال النشر:
- سيعمل التابع `tazkartiWatcher` تلقائياً **كل دقيقة** في السحاب.
- سيقوم بفحص موقع تذكرتي `https://tazkarti.com/data/matches-list-json.json`.
- فور ظهور مباراة لمنتخب مصر أو الأهلي، سيتم إرسال إشعار فوري إلى هواتف المشتركين.

## 📱 اختبار الإشعار الفوري على هاتفك الآن

للتأكد من ظهور الإشعار على شاشة الهاتف وشاشة القفل بصوت واهتزاز:

### الطريقة الأولى (من داخل التطبيق مباشرة):
1. شغل التطبيق على هاتفك: `flutter run`.
2. ادخل على تبويب **"التنبيهات والإعدادات"**.
3. اضغط على زر **"إرسال إشعار تجريبي الآن"**.
4. سيظهر لك إشعار منبثق (Heads-up) أعلى الشاشة وعلى شاشة القفل مباشرة!

### الطريقة الثانية (عبر رابط الـ HTTP السحابي):
بعد عمل `firebase deploy`، ستحصل على رابط مباشر لإرسال إشعار تجريبي لمباراة مصر، يمكنك فتحه من أي متصفح:
```bash
https://<region>-<your-project-id>.cloudfunctions.net/sendTestNotification?team=egypt
```

## 🔋 دليل هواتف شاومي وأوبو وسامسونج (Background Notifications)

بعض واجهات أندرويد الصينية (MIUI / HyperOS / ColorOS) تقوم بتعليق التطبيقات في الخلفية لتوفير البطارية. لضمان وصول الإشعار في ثوانٍ:
1. **التشغيل التلقائي (Autostart):** إعدادات الهاتف > التطبيقات > تنبيهات تذكرتي > تفعيل "التشغيل التلقائي".
2. **توفير شحن البطارية (Battery Saver):** اضبط قيود التطبيق على **"بلا قيود" (No restrictions)**.
3. **شاشة القفل (Lock Screen):** تأكد من تفعيل "إظهار المحتوى على شاشة القفل" و"الإشعارات المنبثقة" لقناة `tickets_high`.

*(توجد شاشة مخصصة داخل التطبيق تشرح هذه الخطوات للمستخدمين بالتفصيل).*

## 🧪 تشغيل اختبارات الوحدة (Unit Tests)

### 1. اختبارات الـ TypeScript / Firebase Functions:
```bash
cd d:/tazkarti/functions
npm test
```
- تختبر تطبيع النصوص العربية (الهمزات، التاء المربوطة، الألف المقصورة، التشكيل، التطويل).
- تختبر المطابقة الصارمة (التأكد من أن "مصر" لا تطابق "المصري" أو "مصر المقاصة").
- تختبر مباريات الذهاب والإياب وتخطي المباريات المحذوفة.

### 2. اختبارات بايثون:
```bash
cd d:/tazkarti
python -m pytest watcher/tests
```
- تختبر دورة التحقق من بنية البيانات (Shape Validation).
- تختبر الحفظ الصامت في أول تشغيل (`SEED_SILENTLY=True`).
- تختبر الانتقالات (Transition Logic) وعدم تكرار الإشعارات (Idempotency).
